Privacy Policy – youtube-ing

Last updated: 2026-11-09

youtube-ing is a private tool operated by nightcabin.lab (the "operator") to manage the operator's own YouTube channels. It is used only by the operator, on the operator's own computer.

Information accessed

When the operator signs in with Google, the tool requests these YouTube and YouTube Analytics permissions on the operator's own channels:

  • Manage the operator's YouTube account, and upload videos and thumbnails.
  • View the operator's YouTube account and channel information.
  • View YouTube Analytics reports and revenue reports of the operator's own channels.
  • Read and post comments on the operator's own videos.

How the information is used

  • To upload the operator's own videos and metadata.
  • To produce internal performance reports about the operator's own channels.
  • To manage comments on the operator's own videos.

Summary reports may be delivered to the operator's own private messaging account. The information is not used for advertising.

Storage

Sign-in tokens and downloaded statistics are stored only on the operator's own computer. The tool has no public server and does not store information about any other person.

Sharing

The information is not sold, rented or shared with third parties, and is not used to train machine learning models.

Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

The tool uses YouTube API Services. By using it, the operator is bound by the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The operator can delete the locally stored tokens and statistics at any time. To ask about data handling, write to the contact address below.

隱私權政策（中文）

最後更新：2026-11-09

youtube-ing 是 nightcabin.lab（以下稱「營運者」）自用的私人工具，用來管理營運者自己的 YouTube 頻道，只在營運者自己的電腦上使用。

存取的資料：營運者以 Google 帳號登入後，工具會對營運者自己的頻道要求 YouTube 與 YouTube Analytics 權限：管理帳號與上傳影片和縮圖、檢視頻道資訊、檢視 Analytics 與收益報表、讀取並發布自己影片下的留言。

用途：上傳營運者自己的影片與中繼資料、製作自己頻道的內部績效報告、管理自己影片下的留言。摘要報告可能會送到營運者自己的私人通訊帳號。資料不用於廣告。

儲存：登入權杖與下載的統計資料只存在營運者自己的電腦上。工具沒有公開伺服器，也不儲存任何其他人的資料。

分享：資料不出售、不出租、不與第三方分享，也不用於訓練機器學習模型。

Google 政策：對於從 Google API 取得的資訊，其使用與轉移遵守 Google API Services User Data Policy，包含有限使用要求。工具使用 YouTube API Services，營運者同時受 YouTube 服務條款與 Google 隱私權政策約束。

撤銷與刪除：隨時可至 myaccount.google.com/permissions 撤銷授權，也可以隨時刪除本機的權杖與統計資料。如有疑問請寄至 nightcabin.lab@gmail.com。
